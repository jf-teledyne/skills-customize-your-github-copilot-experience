# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a classic Hangman game in Python that uses strings, loops, conditionals, and user input to let a player guess a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Build the Core Game

#### Description
Create a Python program that chooses a word at random and lets the player guess letters one at a time until the word is solved or the player runs out of attempts.

#### Requirements
Completed program should:

- use a list of words and randomly choose one for each round
- display the hidden word as underscores, such as _ _ _ _
- accept one letter guess at a time from the user
- reveal correctly guessed letters in the hidden word
- track incorrect guesses and remaining attempts
- end the game with a clear win or lose message

### 🛠️ Improve the Game Experience

#### Description
Add polish to the game so the experience is clear, readable, and enjoyable for the player.

#### Requirements
Completed program should:

- show the current guessed letters and remaining attempts after each turn
- prevent duplicate guesses and tell the player when a letter was already used
- include a simple welcome message or title for the game
- use clear, friendly text to explain the result of each guess
- organize the logic into functions to keep the program readable
